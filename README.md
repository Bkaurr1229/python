🐍 PyLearn – Interactive Python Learning Projects
📘 Overview

PyLearn is a collection of beginner-to-intermediate Python projects built to strengthen programming fundamentals while exploring popular libraries like Turtle, Pandas, and Postman.

Each project focuses on hands-on learning — from data manipulation and file creation to building fun, interactive programs.

🚀 Key Features
🗺️ State Guessing Game

Built using the Turtle library for interactive graphics

Displays a blank map where users guess state names

Tracks correct guesses and saves missing ones to states_to_learn.csv

📊 CSV Data Projects

Uses Pandas for reading, writing, and modifying datasets

Demonstrates data cleaning, filtering, and exporting CSVs

🌐 API Testing with Postman

Explores REST API operations — GET, POST, PUT, and DELETE

Focuses on understanding request-response workflows and JSON handling

🧰 Tech Stack

Language: Python 3.12

Libraries:

🐢 Turtle – for graphics and games

🐼 Pandas – for data manipulation

Tools:

📮 Postman – for API testing

⚙️ Installation
1. Clone the Repository
cd pylearn

2. Install Dependencies
pip install pandas


(Turtle comes pre-installed with Python on most systems.)

▶️ How to Run

Open any Python file (e.g., us_states_game.py) in your IDE such as PyCharm.

Run the script.

Follow the on-screen prompts to interact with the project.

CSV-related projects will automatically generate new CSV files in the working directory.
